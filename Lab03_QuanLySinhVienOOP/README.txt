LAB 03 - QUAN LY SINH VIEN OOP

Project: Lab03_QuanLySinhVienOOP
Ngôn ngữ: C#
Loại project: Console App
Target Framework: .NET 8

CẤU TRÚC:
- Nguoi.cs: Class cha Nguoi.
- SinhVien.cs: Class SinhVien kế thừa Nguoi, có validation điểm và XepLoai().
- QuanLySinhVien.cs: Quản lý List<SinhVien>, thực hiện thêm/sửa/xóa/tìm kiếm/sắp xếp/lọc.
- Program.cs: Menu và nhập/xuất dữ liệu.

CÁCH CHẠY:
1. Mở file Lab03_QuanLySinhVienOOP.csproj bằng Visual Studio.
2. Chọn Run hoặc Ctrl + F5.
3. Thử các chức năng từ menu 1 đến 8.

QUY ƯỚC XẾP LOẠI:
- 8.5 - 10: Giỏi
- 7.0 - dưới 8.5: Khá
- 5.0 - dưới 7.0: Đạt
- Dưới 5.0: Chưa đạt

Các yêu cầu trong đề bài về kế thừa, constructor, property validation, List<SinhVien>,
LINQ và xử lý nhập sai kiểu dữ liệu đã được triển khai.
